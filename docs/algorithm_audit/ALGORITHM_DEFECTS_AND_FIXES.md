# Algorithm Defects and Fixes

| Defect | Pre-change evidence | Fix | Regression evidence |
|---|---|---|---|
| Cross-discipline clinician percentiles | Metric ranks were computed over the mixed RN/PT/OT DataFrame. Adding unrelated OT rows changed RN/PT ranks and could change RN recommendations. | Rank each metric within `discipline` on the full request pool before ZIP filtering. | Unrelated-discipline additions/removals and row shuffles cannot change the unaffected discipline. |
| Raw modeled need treated as a percentile | `rho` drove both threshold routing and mirrored anchoring directly. | Retain `risk_score_rho_raw`; map it through the persisted reference ECDF to `risk_percentile_u`; use only `u` for routing and anchoring. | ECDF clamp/tie/interpolation, Q0.75, strict-threshold, and anchor-order tests. |
| Constant/invalid threshold sensitivity | The old sensitivity loop changed a Boolean mask while reusing assignments, workload, and outcomes; its 101-row artifact had one TPS/objective/workload value. | Every threshold now resets workload and reruns routes, pools, assignment, capacity, and outcomes with common random numbers. | Assignment signatures and simulated outcomes change in nondegenerate scenarios; constant sensitivity raises an assertion. |
| Threshold routing disabled by default | Runtime config did not implement the stated sponsor policy. | Lock the default percentile to 0.75, enable hard-ZIP routing, preserve strict `>` semantics, and audit missing-ZIP/undersized-pool fallback. | Equality uses ZIP-first routing; the next representable value above 0.75 uses the global route. |
| Incomplete metric canonicalization | Alternate CMS/report labels could be silently treated as missing and imputed; duplicate aliases were not checked. | Add a CY2025 canonical alias map, case/punctuation-insensitive lookup, identical-value deduplication, and conflicting-value rejection. | Alias coverage/deduplication/conflict tests. |
| Raw age-band aliases unsupported | Values such as `80_89`, `80+`, and `90_plus` failed category validation. | Canonicalize all required raw bands while leaving numeric boundaries unchanged. | Complete boundary/alias suite, including numeric 80 versus `80_89`. |
| Incomplete deterministic tie-breaking | RN/PT sorted score ties only by clinician name. | Sort score ties by stable clinician ID and then name; preserve deterministic OT name/ID rotation. | Tie, shuffle, and repeated-run tests. |
| ZIP parser gaps | NumPy arrays and integral numeric tokens inside lists could fail; diagnostics were limited. | Accept lists, tuples, sets, arrays, Series, comma/semicolon/pipe strings, integral numerics, ZIP+4, deduplication, and invalid-token audit. | Leading-zero/array/numeric/dedup/fallback tests. |
| Incomplete internal audit | Full-pool ranks/sizes, raw-versus-percentile distinction, threshold raw equivalent, and imputation provenance were missing. | Add `assignment_audit` without changing the simple response. | Required-key and observed/imputed/synthetic provenance tests. |
| Nominal public pipeline provenance | Manifest entries were blank and hard-coded Reno fallback profiles could be mistaken for observations. | Record official pages/IDs, not-retrieved status, cache/checksum fields, columns, transformations, and explicit `offline_demo_fallback`; label synthetic ZIP history. | Manifest completeness and provenance tests. |
| Generated cohorts used cohort ranks instead of the persisted ECDF | Batch risk percentiles and structural rows could drift from the runtime reference. | Attach exact canonical raw risk by seven-factor profile and map it through the persisted 10,000-profile ECDF everywhere. | Cohort/reference equality and all-2,160-profile structural tests. |
| Feasible P7 mislabeled as an oracle | Regret used a capacity-feasible greedy policy as though it were a mathematical upper bound and hid violations with a clamp. | Treat P7 as a latent-quality comparator; calculate a separate unconstrained latent-information upper bound and assert every policy remains below it. | Upper-bound invariants and nonnegative-regret tests across scenarios/policies. |
| Fixed and one-seed sweeps emitted optimization language | A single threshold or in-sample grid could appear to justify a recommendation. | Require at least two thresholds and two seeds; select on the first split and evaluate on the held-out split. Label fixed and one-seed designs explicitly. | Fixed-threshold, held-out-split, and sensitivity-only tests. |
| Structural ablation/fairness relied on assignment proxies | Diagnostics could report hard-coded routing effects rather than service behavior. | Rerun P4 against a fixed roster for every structural ablation and one-factor counterfactual. | Actual clinician-ID/route-change and structural determinism tests. |
| Rerun identifiers omitted design identity | Different capacity/roster/sparsity designs, and direct helper calls with different input rosters, could collide. | Bind IDs to canonical configuration plus exact ordered patient/roster content and operational controls. | Cross-design and direct-roster uniqueness tests plus 144-cell factorial audit. |
| Shrinkage fallback was unsafe | An absent configuration key could accidentally enable behavior depending on caller defaults. | Default missing `enable_shrinkage` to `false`. | Explicit opt-in regression test. |
| Candidate raw thresholds reused the 0.75 cutoff | Fine-grid rows all reported `0.569621...` even when evaluating 0.00 or 1.00. | Compute a type-7 raw equivalent from the persisted reference for every candidate percentile. | Endpoint, candidate-variation, and all-1,818-row equality checks. |
| Capacity target was dormant in public calibration | The `top_25_percent` label carried a target-share penalty multiplied by zero, so TPS alone selected a threshold with no high-risk cases. | Activate an explicit 10 TPS-point penalty per unit target-share miss and record its units in CLI/artifacts. | The selected 0.79 row has exactly 0.250 selection share; fixed/multi-candidate tests. |
| Incomplete calibration input could be discarded silently | A frame with raw risk but missing factors was replaced by a fully generated cohort. | Require all seven factors and report every missing column. | Missing-input rejection test. |
| Fixed public calibration was mislabeled as a recommendation | A one-candidate call unconditionally emitted simulation-selection language. | Emit `fixed_threshold_only_no_optimization`, `optimization_evaluated=false`, and no recommendation. | Single-candidate regression test. |
| Persisted risk/grid provenance was trusted structurally | Runtime checked sorting/tau but not current config hashes/reference identity; batch ignored the structural sidecar. | Validate the CY2025 lock, component hashes, score-bound reference ID, artifact hashes, sidecar fields, grid checksum, and ECDF equality; expose exact binding in rich audit. | Tamper/config/reference/grid checksum tests and 2,160-row audit. |
| Sponsor evidence loader trusted paths without metadata | A stale CSV at a known path could drive sponsor claims. | Fail closed unless every tier's metadata matches its claimed design, current implementation hashes, reference identity, and evidence flags. | Missing/stale/hash/design metadata tests. |
| PDF manifest did not bind source content | A PDF hash existed, but the corresponding Markdown and source-bundle identity were not cryptographically linked. | Record source Markdown hashes, source-bundle identity, and deterministic manifest identity; invalidate stale links before regeneration. | Source mutation and manifest-binding tests plus final page/hash audit. |

## Intentional non-changes

- `backend_interface.py` was not modified.
- OT was not converted into the RN/PT scoring model.
- The production/demo percentile remains 0.75.
- CY2026 measures were not activated.
- P5 soft-ZIP and P6 capacity optimization remain experimental comparators.
- Clinician shrinkage remains configurable and disabled by default. Available generic count proxies are not treated as identified metric-specific production sample sizes.
